mProxy

Lightweight, scalable, and customizable IoT API gateway for multi-protocol proxying and real-time packet manipulation.

Overview

mProxy enables seamless communication across MQTT, CoAP, HTTP and WebSocket, offering on-the-fly packet manipulation, pluggable authentication, observability integrations, and flexible deployment modes (sidecar or standalone).

Source and docs: github.com/absmach/mproxy

Key Features

  • Multi-protocol support: MQTT, CoAP, HTTP, WebSocket
  • On-the-fly packet inspection & transformation
  • Pluggable authentication (OAuth, JWT, API keys)
  • Observability: metrics, logging, tracing (Prometheus/Grafana/OpenTelemetry)
  • Lightweight Go implementation, suitable for edge or cloud

Deployment & Usage

mProxy can run as a sidecar alongside a broker or as a standalone service. Example usage:

git clone https://github.com/absmach/mproxy.git
cd mproxy
make
./build/mproxy

Configuration

mProxy is configured via environment variables (prefixed with MPROXY_). Typical variables include:

  • MPROXY_MQTT_WITHOUT_TLS_ADDRESS - inbound address (default :1884)
  • MPROXY_MQTT_WITHOUT_TLS_TARGET - outbound target (e.g. localhost:1883)
  • TLS and mTLS specific variables (MPROXY_MQTT_WITH_TLS_CERT_FILE, etc.)

See the repository README for full environment variable list and examples.
